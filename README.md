Mission

Design and build an Enterprise AI Hotel Management System (AI-HMS) where an AI Booking Manager performs the daily responsibilities of a Front Desk Manager while maintaining human approval for critical decisions.

This is not a hotel booking website.

It is a complete hotel operations platform similar in quality to Opera PMS, Cloudbeds, HotelKey, or Oracle Hospitality, enhanced with autonomous AI capabilities.

The project should be production-ready, modular, scalable, secure, and extensible.
